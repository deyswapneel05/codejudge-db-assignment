# CodeJudge Database System - Part 1

This repository contains the database relational design, 3NF schema, structure explanations, and table definition SQL scripts for the CodeJudge Online Coding Platform Assignment.

## Repository File Tree
* `schema_explanation.md` - Analysis of raw CSV files and entity separation rules.
* `keys_and_relationships.md` - Primary, foreign, and constraints tracking logic.
* `normalization_notes.md` - 3NF reduction theory and database trade-offs.
* `schema.sql` - Production-ready Data Definition Language scripts.
* `erd.md` - Complete Mermaid-based structural Entity Relationship Diagram.
* `assumptions.md` - System layout assumptions.
